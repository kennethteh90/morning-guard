    How this relates to AppScreens
    • Design once, export many sizes — AppScreens markets a responsive engine so one project adapts to iPhone, iPad, Android, and more (appscreens.com).
    • Templates + device frames — Their editor layers titles, backgrounds, and real/clay/3D device mockups on a canvas.
    • Workflow — Pick layout → import raw screenshots → customize → download PNGs (they also offer localization and direct App Store Connect / Play upload on paid tiers).
    • This studio — Offline, repo-local tool: Morning Guard colors, default ASO copy, presets for common Apple/Google dimensions, canvas PNG export. No account, no upload API.

    Quick start

    1. Capture raw screens on a device or emulator (no frame).
    2. Upload PNGs above; edit titles per slide.
    3. Choose App Store or Play preset; export all.
    4. Upload PNGs in App Store Connect or Play Console.
